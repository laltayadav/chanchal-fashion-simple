# Proposal: Scaffold Next.js storefront

## Summary
Build a simple, JSON-backed storefront for Chanchal Fashion using Next.js App Router, Tailwind CSS, and a lightweight data layer under the repo's data directory.

## Goals
- Provide a working home page, cart page, and admin pages.
- Add API route placeholders for products, orders, and config.
- Create a file-based data structure that can evolve into a real persistence layer later.

## Non-goals
- Full checkout/payment flow.
- WhatsApp notifications.
- Production deployment automation.
